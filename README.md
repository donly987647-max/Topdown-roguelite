# Topdown Roguelite MVP

모바일 브라우저에서 바로 테스트할 수 있는 HTML5 탑다운 로그라이트 MVP입니다.

## 바로 플레이

- 개발용 즉시 실행: https://raw.githack.com/donly987647-max/Topdown-roguelite/main/index.html
- GitHub Pages: https://donly987647-max.github.io/Topdown-roguelite/

## 플레이

- 모바일: 왼쪽 가상 조이스틱으로 이동, 오른쪽 `DASH` 버튼으로 회피
- 공격: 가장 가까운 적을 자동 조준하고 자동 사격
- PC: `WASD` 또는 방향키 이동, `Space` 대시

## 현재 구현

- 무한 생존형 전투
- 3종 적 타입 및 시간에 따른 난이도 상승
- 자동 조준·사격
- 체력, 피격 무적, 대시
- 처치 수 기반 자동 레벨업
- 게임 오버 및 재시작
- GitHub Pages 자동 배포

## 개발 방향

이 버전은 조작감과 모바일 성능을 확인하는 MVP입니다. 이후 방 단위 진행, 장검·창·권총, 보상 선택, 유물, 상점, 세이브, 픽셀 아트를 순차적으로 추가합니다.
