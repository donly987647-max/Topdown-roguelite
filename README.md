# Topdown Roguelite

Godot 4로 개발하는 2D 탑뷰 로그라이트 게임입니다.

## 현재 빌드

첫 번째 플레이어블 프로토타입을 구축 중입니다.

## 실행 환경

- Godot 4.3 이상 권장
- 키보드 + 마우스

## 기본 조작

- 이동: `WASD` 또는 방향키
- 조준: 마우스
- 공격: 마우스 왼쪽 버튼
- 대시: `Space`
- 재시작: `R`
- 종료: `Esc`

## 개발 원칙

- 작은 기능 단위로 구현 후 GitHub에 계속 반영
- 외부 에셋 의존도를 낮춘 플레이 가능한 프로토타입 우선
- 이후 픽셀 아트, 무기, 방 생성, 보상, 유물, 영구 성장 시스템을 순차적으로 추가
