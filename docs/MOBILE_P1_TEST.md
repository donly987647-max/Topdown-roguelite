# P1 Mobile Validation Build

This APK exists only to validate the shared P1 combat feel on Android.

## Touch layout

- Left stick: movement
- Right stick: aim and automatic service-pistol fire while held outside the deadzone
- DASH: fixed-direction dash using current movement direction, or aim direction while stationary
- RELOAD: starts the 1.15 second reload

## Mobile validation scope

The APK can validate movement response, dash distance and invulnerability readability, pistol cadence, enemy telegraph clarity, hit-cause readability, camera comfort, screen shake, audio distinction, frame stability and five-minute softlock safety.

Mouse aiming, keyboard movement, desktop gamepad switching and desktop UI scale remain separate PC checks.

## Installation

This is a debug-signed internal APK. Android may request permission to install unknown apps for the browser or file manager used to open it.
